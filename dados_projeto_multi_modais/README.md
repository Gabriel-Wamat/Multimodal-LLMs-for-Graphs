# Dados recebidos

Esta pasta é o ponto de entrada dos CSVs, parâmetros e gabaritos obtidos separadamente. Os arquivos originais não são distribuídos neste repositório nem enviados ao Git.

A estrutura e os campos esperados estão em [docs/data.md](../docs/data.md). Preserve os arquivos recebidos e gere os derivados em `data/processed/`.
