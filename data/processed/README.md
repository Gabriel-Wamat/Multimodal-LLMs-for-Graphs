# Dados derivados

Os gráficos reconstruídos ficam em `graficos/`; `gabarito.xlsx` é uma cópia navegável da planilha recebida, com links relativos para os PNGs. A geração preserva o original e verifica hashes, 720 imagens de 1500×900 pixels e os links da planilha.

Pares A/B têm sua própria pasta/versionamento. Nenhum desses artefatos é distribuído no Git. Convenções e execução: [docs/data.md](../../docs/data.md).
