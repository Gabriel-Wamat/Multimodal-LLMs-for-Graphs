# Manifestos gerados

Imagens, entradas, gabaritos, splits, famílias e pares são registrados aqui pelos comandos de preparação. O Git publica apenas este guia; os manifestos das suas execuções permanecem fora do versionamento porque podem conter dados ou caminhos da instalação.

Não copie gabaritos para os prompts dos modelos. Confira os hashes e a versão do split antes de combinar experimentos. Veja [dados](../../docs/data.md) e [experimentos](../../docs/experiments.md).
