# Registros de execução

Esta é uma área de trabalho gerada pelos executores, fora do Git. Ela guarda configurações resolvidas, fontes congeladas, auditorias, submissões, históricos e checkpoints de treino. Não é um inventário de jobs ativos.

Os dados de uma execução devem ser preservados com seus hashes; uma fonte alterada exige outro ID. A documentação pública fica em [docs/experiments.md](../docs/experiments.md), e o snapshot numérico compartilhável está em [results/published/](../results/published/).
